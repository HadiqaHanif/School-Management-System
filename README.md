 Student Management System (OOP - Python)

This is a beginner-friendly Python project that demonstrates the fundamentals of Object-Oriented Programming (OOP) using a `Student` class.

Features

Create student objects with:
  * Name
  * Age
  * Roll Number
  * Marks
* Display student information.
* Check whether a student has passed or failed.
* Assign grades based on marks.

Grade Criteria

* A+: 90–100
* A: 80–89
* B: 70–79
* C: 60–69
* D: 40–59
* F: Below 40

 Concepts Used
* Classes and Objects
* Constructors (`__init__`)
* Instance Attributes
* Methods
* Conditional Statements (`if`, `elif`, `else`)

This project is part of my Python OOP learning journey and focuses on building a strong foundation in object-oriented programming.
